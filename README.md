## VisiTank: local desktop software for industrial inspection

VisiTank is my Windows desktop application for modeling storage-tank floors, organizing inspection findings, and producing engineering drawings and reports. It is a substantial part of my enterprise software work; its source is private.

My work on VisiTank brings together:

- **Model-driven software development:** tank, plate, geometry, and inspection models drive the editing workspace, saved projects, and generated outputs. The same domain information flows through the application instead of being re-entered for every deliverable.
- **C# and WPF application engineering:** an interactive 2D CAD workspace, data-bound setup screens, custom geometric calculations, plate editing, annotations, and undo actions.
- **Data and reporting workflows:** Excel inspection imports, editable saved sessions, Word reports, spreadsheet exports, and drawing exports.
- **Desktop delivery:** hardware-bound signed licenses, local offline license validation after activation, Windows-protected license storage, and installer packaging.

The application supports inspection documentation and visualization. Engineering acceptance decisions and standards certification remain the responsibility of qualified reviewers.
